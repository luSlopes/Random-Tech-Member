## Overview

Random tech member is a system built in react for generate, randomly one of the members of the technology subsector of focus consultoria (at least in the second semester of 2026)

## Structure

```
random-tech-member/
├── src/
│   ├── api/            # Definition of the in memory database
│   ├── assets/         # Images used
│   ├── cards/          # Card components
│   ├── functions/      # Auxiliar functions
│   ├── App.tsx         # Application entry-point and logic
│   ├── frontend.tsx    # Rendering root element
│   ├── index.css       # Global and especific styles
│   ├── index.ts        # Start the server of the app
```

## Stack

- React
- TailwindCSS
- Typescript
- Bun

## Getting started

### with npm:

```
npm install
npm run dev
```

### with bun

```
bun install
bun run dev
```

Access http://localhost:3000
